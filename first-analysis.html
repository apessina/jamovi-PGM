5  Running an analysis

5.1 Opening the analysis

To begin:

  1. Open the dataset in jamovi.
  2. Select PGM from the analysis ribbon.
  3. Open Growth Curve Modeling.
  4. Assign one or more Dependent Variables.
  5. Assign the numeric Time Variable.
  6. Configure one or more rows in Model Setup.

A model setup defines the response variable, growth model, residual variance structure, residual correlation structure, and optional fixed asymptote.

5.2 Model parameterization

PGM provides two location parameterizations for the Unified growth-model family.

5.2.1 Ti

The Ti parameterization reports the time of the inflection point.

This form is useful when the timing of maximum growth rate has a direct biological interpretation.

5.2.2 W0

The W0 parameterization reports the fitted response at \(t=0\).

This form may be useful when the initial value has a direct biological interpretation or when comparison at a common temporal origin is important.

The parameterization is selected globally for the analysis and the corresponding parameter label is updated in the Fixed Effects and Random Effects sections.

5.3 Selecting a growth model

Each setup may use one of the following Unified models:

  • Richards;
  • Gompertz;
  • Logistic;
  • von Bertalanffy.

The three-parameter models are special cases of the Unified-Richards family and retain the same interpretation of the common parameters.

Richards additionally estimates the shape parameter \(d\).

Different equations should be compared using model adequacy, biological plausibility, convergence, and residual diagnostics rather than fit statistics alone.

5.4 Fixed asymptote

A positive value may be entered in the Asymptote column of a Model Setup.

When supplied, \(A\) is treated as fixed rather than estimated for that setup.

This may be useful when the upper asymptote is externally known or when incomplete late-stage data make free asymptote estimation scientifically inappropriate.

Because \(A\) is then not an estimated parameter, fixed or random effects assigned to \(A\) are not fitted for that setup.

5.5 Residual variance

The Variance column controls the residual variance function.

Available options are:

  • None;
  • Power;
  • Exponential;
  • Constant-plus-power.

Use a variance function when residual spread changes systematically with the fitted response.

5.6 Residual correlation

The Correlation column controls residual serial dependence.

Available options are:

  • None;
  • AR(1);
  • CAR(1).

When AR(1) or CAR(1) is selected, one or more variables must be assigned under Correlation Groups.

AR(1) is most appropriate for approximately equally spaced repeated observations.

CAR(1) uses the actual temporal distance and is generally preferable for irregularly spaced observations.

5.7 Fixed Effects

The Fixed Effects section assigns predictors to individual growth parameters.

For example, the terms

sex
treatment
sex:treatment

assigned to \(A\) specify:

\[ \log(A) = \beta_0+ \beta_1\,sex+ \beta_2\,treatment+ \beta_3\,sex\times treatment. \]

The exact internal parameter scale depends on the selected growth parameter.

Main effects and interaction terms are specified explicitly. An interaction does not replace its component main effects unless that is the intended model.

The same fixed-effect specification is applied to each model setup in which the corresponding structural parameter is estimated.

5.8 Random Effects

The Random Effects section assigns grouping terms to individual growth parameters.

For example, the Imperial Shag dataset distributed with PGM contains chick and nest identifiers (Svagelj et al. 2021):

A: chickID

allows the asymptotic parameter to vary among chicks.

Different growth parameters may receive different random grouping structures.

Multiple nested levels are also supported. For example:

nestID
chickID

may represent chicks nested within nests when the data support that hierarchy.

A composite term such as

species:replicate

creates a grouping factor from the unique combinations of its components.

Random-effect interaction terms therefore describe combined grouping units; they are not fixed-effect interactions and are not random slopes for predictor variables.

Within each grouping level, PGM currently uses a diagonal covariance structure for multiple random growth parameters.

5.9 Correlation Groups

Correlation Groups define the grouping hierarchy for residual autocorrelation.

For example:

nestID
chickID

corresponds to an outer-to-inner hierarchy equivalent to nestID/chickID.

When random effects are also present, PGM reconciles their hierarchy with the selected correlation groups and stops with an informative error if the structures are incompatible.

5.10 Estimation pathway

PGM always starts from a Levenberg–Marquardt nonlinear fit.

The final estimator then depends on the requested model:

  • ordinary NLS when no fixed effects, random effects, variance function, or residual correlation are requested;
  • GNLS when fixed effects and/or residual variance/correlation structures are requested without random effects;
  • NLME when at least one random effect is requested.

5.11 Recommended workflow

A defensible analysis commonly follows this sequence:

  1. inspect the observed trajectories;
  2. select a biologically plausible Unified growth model;
  3. assess the basic parameter estimates and convergence;
  4. add scientifically justified fixed effects;
  5. add random effects when repeated or hierarchical units require them;
  6. inspect residual spread and consider a variance function;
  7. inspect serial dependence and consider AR(1) or CAR(1);
  8. evaluate parameter plausibility and model diagnostics;
  9. compare candidate specifications using compatible data and likelihoods;
  10. interpret derivative-based descriptors only after accepting the underlying fitted model.

5.12 Multiple modeling setups

PGM allows several response-model setups in the same analysis.

This can be used to compare:

  • different Unified growth models;
  • residual variance structures;
  • residual correlation structures;
  • fixed versus estimated asymptotes;
  • different response variables.

Fixed Effects, Random Effects, Correlation Groups, and the selected Ti/W0 parameterization are analysis-level specifications and apply to all compatible setups.

Formal comparisons require the same response observations and compatible likelihood definitions.
